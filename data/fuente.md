# Fuente de datos

**Dataset**: Online Retail II

**Cita**: Chen, D. (2012). *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D

**Origen**: UCI Machine Learning Repository — https://archive.ics.uci.edu/dataset/502/online+retail+ii

**Licencia**: Creative Commons Attribution 4.0 International (CC BY 4.0) — se puede usar y adaptar libremente citando la fuente.

**Descripción**: transacciones de una tienda online del Reino Unido, no-tienda registrada, especializada en regalos para todas las ocasiones; muchos clientes son mayoristas. Dos hojas de Excel: "Year 2009-2010" y "Year 2010-2011", con columnas `Invoice`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `Price`, `Customer ID`, `Country`.

**Archivo local**: `data/raw/online_retail_II.xlsx` (no se sube al repo, está en `.gitignore`; se obtiene descomprimiendo `online+retail+ii.zip` descargado directamente de UCI).
